- **Symbols against resolved values** (amends round 1): no pre-pass. Equality resolves a pair
  (symbol as written vs a Member/Ref/case of a resolved value) lazily inside the equality walk,
  recursively, each resolved pair charged as a step; symbol-vs-symbol stays by name (stage A).
  Verification retypes every container it converts (`List.T`/`Map.T` to the computed type), so a
  lookup, `in`, an insert and the set built-ins (`unique`, `isUnique`, `union`, `intersect`,

  branch, a string or integer literal to a `ref` key; a loaded wire value counts as a literal
  (it is written text). A computed `Int`/`String` of the wrong kind is E3802. Float32 branches
  round to binary32 as storage does; the other §6.2 conversions (an entry to a ref, E3503; a ref
  dereferenced to a record) apply at a dependent branch as at any storage point: verification
  reuses eval's storage conversion for everything that is not a symbol.
- **`none` on a dependent field** is judged at verification against the computed type: E3801
  when it computes `Never` and the field is not optional, E3802 when it computes a non-optional
  type; the checker's static acceptance (§11.4, the union of branches) is unchanged.

  computes for the whole, not the part's element type (ERRORS' `{dep} = {typ}` must be true).

  applications, bare-case defaults, a `where` predicate's first run — is charged to that value's

- **No in-place mutation** (EVALUATION §4.1): verification converts by copy-on-change at every
