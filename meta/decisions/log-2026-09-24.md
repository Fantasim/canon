## build wiring (M2)
- **No E9008 cascade:** a package whose tests carry any error finding reports no `E9008` (its
  calls cannot be known; "no cascades across phases"); `E9009` is unaffected. progen's
  expectations and the `mutation_E8015…` archive are refreshed by progen's owner.
- An expect subject whose verification poisons it gets no instance checks (as stage C). An
  unsupported load forced during test collection or inside a vector fails the build with `ErrLoad`
  (196). A compile-and-run test of `canon build --target cpp` output needs gen/cpp's compile helper
  in `internal/testkit` (cleanup owed). `canon build pipeline` output vs expected: see GEN-01.
- "Tests carry an error" means a test the checker left broken (`Info.Broken`: an error in the test
  or in a declaration it names); a test stopping at run time before its call still leaves `E9008`
  (§6.1 keeps calls made before a stop; `canon test` reports the stop).
- **build wiring review (amends 204's premise):** conformance runs in check and build before the
  error gate, so a vector or precomputed self read can meet a poisoned value. When it does and the
  bags already hold an error, that call or vector is skipped (no vector from it, no `E9008` for it;
  the stage-A finding stands); `ErrNoOutcome` stays internal only when no error was reported.
  Test-call collection applies the invocation's active layers (as `canon test --layer`). Verify and
  rules program indexes are built once per run and shared across subjects and vectors (additive
  constructors in verify and rules). On a Fill error, stageE joins the host's errors; a cancelled
  context outranks both.
- **Open formatter bug (recorded by hand, the generator no longer produces it):** `canon fmt` breaks
  a line after `count??` inside a match arm's function type, and the reparse gives E1117 (the
  "never break where the grammar forbids a line end" rule above). Owner: format; its fix adds a
  regression test by hand.
- M1.5's archives are derived against the tree they ran on; after the build-wiring unit lands,
  TestCounterexamples re-checks them and changed signatures are re-derived before M1.5 is committed.
- Owed by the `canon test` unit: an `expect` subject's unbound refs (`E3505`) reach its capture
  (needs a capture-aware `ReportUnbound` in eval); conformance call collection is unaffected.
