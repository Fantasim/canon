## load.dir review (M2)
- **Missing base directory or literal file** of a load form is `E7004` (WIRE §13 "missing file,
  directory"), not `W7107`; W7107 is only a pattern that walks and matches nothing.
- **A trailing `**`** matches every file at any depth under the base. **Nested braces**
  `{a,{b}}` are `E7005`. **`.` or `..` segments in the glob part** are `E7001` (a walk cannot
  match them; refusing is stricter than normalizing).
- **M2 scope cut:** `load.dir` of JSON with literal-kind defaults only; other element types,
  options and non-literal defaults are refused with `ErrUnsupported` carrying its cause, which
  `LoadError` prints (196: every refusal names its cause). An unknown extension is `E7007`.
- **Field defaults in decode:** until the evaluator backs `wire.Host.Default` (an additive §4.8
  change, done with the eval wave), `supported` refuses a default whose literal kind is not the
  field's base kind, and values are built as the evaluator builds them (T from the non-optional
  base, `Prov.Span` set).
- **`E7004`/`E7005` `{cause}`** is a fixed vocabulary (for E7004 chosen by `errors.Is`, never OS
  text or a path); it moves into ERRORS.md/`internal/diag` in the ERRORS.md pass.
