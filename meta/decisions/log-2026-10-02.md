## A1 `canon edit` rulings

- Undo across processes: a fresh `Project`'s revision covers only what it read (S3), so a printed
  `undo.base` was stale in the next run. Ruled: `canon edit` checks every package before `Edit`;
  CLI.md §3.15 says so. Cost is one cold check per call (2.5 s on the benchmark), acceptable for a CLI.
- Byte identity: API.md E22 promises values, not text (a removed one-line entry comes back
  multi-line). M5 acceptance amended: values always, bytes where the edit kept the layout.

  FS that serves open buffers before the disk, so the first `Open` already sees them (§8.4 Sync:
  every change is an overlay, from the first pass).

  cancellation; they are applied in a step that holds no ctx, before the ctx-bearing check.

  `guard` calls it; a panicked pass requeues its dirty keys.

- A buffer of a JSON file outside the project directory (under a root) is not an overlay: API.md
  §15 gives an overlay outside the project as ErrBadPath. Its findings come from the disk.
- `projectAbove` maps only ErrNoProject to "loose"; other errors are reported.
