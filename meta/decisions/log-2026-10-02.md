## A1 `canon edit` rulings

- Undo across processes: a fresh `Project`'s revision covers only what it read (S3), so a printed
  `undo.base` was stale in the next run. Ruled: `canon edit` checks every package before `Edit`;
  CLI.md §3.15 says so. Cost is one cold check per call (2.5 s on the benchmark), acceptable for a CLI.
- Byte identity: API.md E22 promises values, not text (a removed one-line entry comes back
  multi-line). M5 acceptance amended: values always, bytes where the edit kept the layout.
