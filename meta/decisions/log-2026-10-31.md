## Calls (technical, the orchestrator's)

The roadmap's §7 gives a verdict on every ask. The calls that refuse or reshape one:

- **A `CAr`-compatible byte layout: refused.** Byte-identical legacy writers are refused (ruling B1,
  DECISIONS 327). Each message switches format under Sovereign's version gate; both peers ship
  together, so no byte compatibility is needed.
- **Member widths from refinements: refused** (GEN-02, CODEGEN §4.1). The width is declared:
  `Int32(1..=n)`.
- **Checked decode: kept.** Range and length refinements are checked by every decoder. Patterns and
  `where` stay build-time. This amends CODEGEN §5.13 and WIRE §5.13.
- **Audience projections as a per-field knob: refused.** One record per audience, plus a projection
  fn (v0.4).
- **Per-field `since N`: refused.** The schema fingerprint is the version, exchanged at the handshake
  (v0.6).
- **Types that change with build flags: refused.** One schema per project.
- **Translated code:**
  - `while` is refused, because generated code has no step budget; bounded `for` is kept.
  - A real-exponent `pow` is refused; a lookup over a finite domain replaces it.
- **Bit operations: builtins, not operators.** `|` is already union and line continuation (GRAMMAR
  §5.9, SPEC §2.3), and C's `&`-below-`==` precedence trap stays out of the language.
- **Lookup versus translation: one rule with a cell bound** (v0.4 #3), not v0.3. Moving a fn
  between the two changes the WIRE §5.11 `$` keys, the fingerprints, and its C++ constexpr
  (DECISIONS 293).
- **Compact JSON or an indent option: refused** (one form, DECISIONS 327). Consumer-declared pruning
  lists: refused.
- **One shared runtime per root for C++ and Go: not scheduled.**
  - Each output directory is self-contained by design (ADR-0022 §10).
  - Building it is large: 12+ files, and a field on the frozen `ir.Emit`.
  - TS gets one runtime module per directory if the helper block per file is large (v0.3 #5).
- **Macro clashes across packages:** a read-only Resource scan first. The lean is a refusing check
  with a way out, over a guard set widened to the whole project, because a package's output stays a
  function of what it reads (roadmap §3 #6).
- **Order:**
  - v0.2: trust;
  - v0.3: lean output (`ordered_json`, kind constants and N8 move here from v0.2);
  - v0.4: formulas;
  - then, as direction: v0.5 binary data with N2, and v0.6 runtime values;
  - N3 goes into v0.3.

## Spec gaps found

- CONFORMANCE §3 lists Float `%`; TYPES §7.1 types `%` on Int only.
- E9001, E9006 and E8104 name no way out (DECISIONS 305). E9006's message also omits Float32.
- CODEGEN §6.3 differs from the Go runtime (`rt.go.txt`) by 259 lines, and §7.5 excerpts 213 of its
  1,466 lines.
- To verify in v0.4:
  - translated recursion, which is allowed today, has no stated run-time bound;
  - the floating-point contract (fast-math, FMA contraction) behind the bit-exact claim.
- Latent, v0.3 #7: the C++ runtime guard is keyed by version, not by content, so a stale copy of the
  same version can shadow a newer one.
- Already owed (log-10-21): `@cpp(defines:)` guards count names met inside string literals; the guard
  scan skips neither comments nor strings.
