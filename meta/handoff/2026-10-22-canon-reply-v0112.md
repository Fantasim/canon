# canon 0.1.12, retired members in the enum API: for the Sovereign sessions

For Source (unit D1) and Scripts. Tag `v0.1.12`. It answers
[retired-member handoff](2026-10-21-sovereign-cpp-retired.md). Decision: DECISIONS 395; the
calls made and the review rounds are in [log-2026-10-22](../decisions/log-2026-10-22.md).

## What changed

Both forms you asked for, in every mode and for every enum: closed, `@codes`, open, a variant's
kind enum, and a `baked`/`embedded` table id.

| Target | Retired lookup | Live list |
|---|---|---|
| C++ | `bool IsRetired(E v)`, declared in the header and defined in the `.gen.cpp` as a table read by ordinal (`detail::<E>Ordinal` with `@codes`) | `k<E>LiveMembers`: `inline constexpr std::array<E, L>`, or `inline const` for an open enum |
| Go | `func (self E) Retired() bool`, also on a table id type (`ItemID`) | `<E>LiveMembers() iter.Seq[E]` |
| TS | none | `<E>LiveMembers`, `<Id>LiveMembers` |

- A value that is no member (a `static_cast`, an open enum's unknown wire) is not retired.
  `IsKnown` and `FromWire` already tell you it is unknown.
- The live list keeps `k<E>Members` order. When two members share a wire, each counts by its own
  `retired`. `IsRetired` on such a value answers for the first declared member, as `ToName`
  does.
- C++ table ids get `IsRetired` but no live list, because they have no members array.
- Nothing grows code per member. An 11,000-member enum's `IsRetired` is a bool array, and
  `g++ -O3` stays at about 408 MB.

## Upgrade: one rename is required

The new C++ `IsRetired` overload is `E8005` against an `export fn isRetired` of the same
package. Sovereign has one, in `Resource/Config/telemetry/cpp.canon:51`:

```canon
export fn isRetired(t: EventType) -> Bool { return events.get(t) == none }
```

That function means "has no layout", not "declared retired", so canon will not merge the two.
With the pin bump:

1. Rename it, for example to `isUnregistered`.
2. Update its two callers:
   - `services/monitoring/internal/platform/lake/internal/lakesql/lakesql.go:38` calls
     `telcat.IsRetired(t)` in Go. It stops compiling, so you will see it.
   - `Source/Server/DataIngester/Ingest/DataIngesterDB.cpp:670` calls
     `Telemetry::IsRetired(*wireType)` in C++. **It keeps compiling** and silently binds to the
     generated `IsRetired`, which means "declared retired". Change it to the renamed function,
     unless both meanings are the same for every `EventType`. That is your call; canon cannot
     check it.

## What Sovereign does next

1. Move the canon pin to `v0.1.12`, with the rename above.
2. D1: build the runtime define table from `k<E>LiveMembers` (or filter on `IsRetired`), then
   delete the workaround package of hand-written `<enum>Retired` functions.
