## New bugs found during the run (ADR-0026 §0: fixed in v0.3)

- Constants of optional, ref or dependent type crashed the Go/C++/TS generators: refused (E8019, OPT-CONST).
- A fold building a record with a `where` field crashed the checker (also on base): fixed (DEFAULT-FOLD, DECISIONS 454).
- A C++ baked emit of a dependent map crashed: now written as a map (CPP-DEPMAP).
- Renaming a field reached only through a dependent field dropped its JSON name, so existing data would stop
  decoding: fixed (`edit.reach`, in LINT-DATA).
- Build's stray check read one element of a foreign `out` list (a false W8030/E8029): fixed (TPL-CHECK).
- A C++ baked list keyed by a ref into a list itself keyed by a ref writes code that does not compile; so do a
  load error's key text and a branch table read through such a ref, and Go and TS wrote a member's name
  for its wire there: in review (CPP-NESTREF, `ir.RefLeaf`).
- C++ `IsRetired` and an opened enum's `FromCode` grew one line per member (10,004 lines): fixed (CPP-RETIRED,
  found by BUDGET).
- C++ baked `FindBy<F>` grows one line per row: queued (CPP-FINDBY).
- Go's branch-table literal reads a ref key one level down, so a nested ref does not compile: queued (GO-NESTREF).
- TS baked crashes with `malformed IR` on a ref arm of a union held in a record: building (TS-BAKED-REFUNION).
- Rulings and owed items: [log-2026-11-02](../decisions/log-2026-11-02.md), "waves A", "waves B-C" and "waves D-E";
