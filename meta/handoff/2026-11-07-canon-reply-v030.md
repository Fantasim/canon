# canon 0.3.0, lean generated code: for the Sovereign sessions

For Resource, Source, Scripts, website, admin, monitoring, wiki, trello and config-studio. Tag `v0.3.0`
(local, annotated, at `06e9912b`; Louis pushes `main` and the tag, then publishes). Decided in
[ADR-0026](../decisions/0026-v03-lean-generated-code.md): DECISIONS 430-452, plus 453-516 from the run's own
bug hunt. Every ruling of the run is in [log-2026-11-03](../decisions/log-2026-11-03.md) and
[log-2026-11-06](../decisions/log-2026-11-06.md); the final acceptance, with every number below, is at the
end of the latter.

Compiler 0.3 reads **language 0.1**: every `canon: "0.1"` project is accepted and no project edits its header
(DECISIONS 452). `canon: "0.2"` stays `E1001`.

## What changed

**Generated code** (no source change needed; regenerate):

- **Enum strings written once**, C++ and Go (430). Dense enums lose their two arrays; sparse ones keep one
  `uint32_t` ordinal table. Resource: the `.gen.cpp` files total **7.57 MB, down from 16.45 MB**.
- **The C++ JSON runtime reads a file in one pass** (431), proven against v0.2.0's reader by a differential fuzz.
- **Baked containers** find their keys in sorted constant tables (432).
- **TypeScript**: top-level values are built by calls a bundler can drop (433, `/*#__PURE__*/` marks only);
  the helper block stays in each file (434).
- **Generated functions stay within a line budget** (435): big C++ `Decode`, Go `decode<T>` and lookups are
  split into parts; Go lookups over a `@codes` enum read the enum's tables (36 files on Resource).
- **C++ runtime copies carry a content stamp** (436): two different copies in one program stop the compile.
- **C++ `Decode` also takes an `nlohmann::ordered_json`** (437); **a variant's kind is a constant** (438).
- A `.gen.cpp` includes every package it names that its header does not (457); a constant with no constant
  form in a target is refused there (453, `E8019`).

**Language and checker** (all refusals; none fires on Resource today):

- A target annotation on a local declaration is `E1118` (443); a default reading a field of a record literal is
  checked as that literal (444); unstored dependent literals are judged, once (446); verification's `where`
  runs are free (447); a negated literal is judged by its negated value (460); a literal union refused by
  `E3002` is the error type (461); `self` in a field default reads only an earlier field (465).
- An element assignment keeps the key of the keyed-list or table slot it fills; another key is the new hard
  error **`E4004`** (512). A layer line keeps the key of the element its path names (**`E1913`**, 499).
- A layer file whose amendments name a broken declaration is broken (514; it was an internal compiler error).
- A narrowing condition in error proves only what some reading of it could prove (516): fewer cascading
  `E3403`s after a typo, and none hidden.
- `E8005` names a way out that works (442, 458).

**Evaluation and speed:**

- Shared values are walked once in stages A, B and C and the wire-form check (504, 507, 509, 511, 513): a
  deeply shared valid value no longer takes exponential time (depth 20: seconds to under 10 ms).
- `canon test`'s verifiers share their ref-target index (515): on Resource, `canon test` takes 60 s, not the
  305 s a mid-run build took (0.2.0: 48 s; see Upgrade notes).
- Identity rules for amended copies (510); every declared layer is evaluated by `check`, `build`, `test` and a
  watch (469, 472).

**Edit, workspace and language server (config-studio):** a long-lived Project no longer grows with its edits
(445); a String-keyed keyed list's word key starts an amend line (450); and 30 correctness rulings for edits
under layers, spreads, renames, refs keyed by refs and `load.dir` tables (455-506), among them: a refusal names
a way out only when it makes the edit pass (462), an edit whose Undo would be refused is refused first (474), an
edit beside a spread writes only its field (467), a poisoned `load.dir` table stays repairable (508), and a
rename under an active layer never rewrites a computed ref (506).

**Build:** a build judges its outputs as inputs before they exist (451, `E8026` on the first run, not the
second); writelock errors name no absolute path.

## Upgrade notes (breaking)

- **A mixed C++ tree now stops at compile time** with canon's `#error` (436): regenerate every C++ output
  with one canon. This withdraws 2026-10-20's "the first copy included wins".
- **`canon test` prints its warnings and exits 4 past `--max-warnings`** (449); **a test with an error
  outside its `expect`s fails** (448). Resource: 795 passed, 0 failed; its pre-push already runs
  `check -max-warnings 0` first. `canon test` holds the check results beside the test run: on Resource it
  takes 60 s and 3.5 GB (0.2.0: 48 s, 1.5 GB). Sharing that work is on the v0.4 list.
- **New refusals:** `E1118`, `E3204` at a record-literal default, `E3802` from unstored dependent literals,
  `E8026` before an output exists, `E8019`, `E4004`, `E1913`. Resource counts on the dry run: **0 for each**.
- **A C++ data loader refuses a NUL after the document** (431).
- **New reserved names:** `E8005` for the generated enum tables and the `Decode<N>`, `build<Last>_<N>` and
  `decode<T>_<N>` parts; `E8011` for the new runtime identifiers. 0 collisions on Resource.
- The language version stays `canon: "0.1"` (452).
- No Go or TypeScript API changes: the five services' `go vet` and `tsc --noEmit` output is identical under
  0.2.0 and 0.3.0. Source keeps compiling: no hand-written `canon::rt_v1`, no `Decode({`, the 13 files using
  `canon::FlatMap` unaffected.

## New

- **`out_templates`** (439): `project.canon` gives an emit's path once; an emit's `out` may name a root.
  Optional for Resource; its outputs stay byte-identical either way (ADR-0026 §11 counts 72 Go, 33 TS and 109
  view emits that could use it; not applied on the dry run).
- **`canon lint`** (440): advisory lints for agents, `W0001`-`W0008`, never an error. On Resource (58 s): 41
  warnings: `W0007` 19 (files over 5,000 lines held by one let, e.g. `textClient.canon`, 79,154 lines),
  `W0001` 10 (legacy type prefixes), `W0005` 6, `W0004` 2, `W0008` 2 (the `WindowIds.h` defines: 1,052
  `WindowId` and 212 `ControlId` names no guard covers), `W0003` 1, `W0006` 1.
- **C++ `Decode` of an `nlohmann::ordered_json`** and **kind constants**: see What changed.

## Recorded misses

- The first `progen-nightly` kept one counterexample: a typo in a narrowing condition (`E2102`) also raised a
  cascading `E3403`. The bug predates v0.3 (0.2.0 the same); fixed before the tag (516).
- The first dry run found `canon test` at 305 s on Resource (0.2.0: 48 s): a ref-target index rebuilt for each
  literal since 446. Fixed before the tag (515).
- Under load 30, `internal/build`'s race run hit its 10-minute timeout and `FuzzDecode` its deadline; both
  passed re-run alone.
- The orchestrator started the final run detached and was not woken when it ended: the machine sat idle from
  01:02 to 04:48. Long runs now always wake the session, on every Claude session of this machine.

## What stays owed (v0.4)

Each is recorded in DECISIONS; none gives a wrong verdict on valid input.

- **Speed:** `canon test` reuses the check pass's work (449; BUILD-TESTCHECKREUSE, EVAL-KEPTLITSRELEASE);
  `x in m` over a map's candidates (VALUE-MAPCANDIDATES); shared values stay exponential only when invalid or
  under a `where` leaf (509, 513: VERIFY-SHAREDFOUND, EVAL-WHEREPERPATH, EVAL-STOREFOUND, IR-SHAREDWALK).
- **Diagnostics:** a span's column (ENTRYSPAN); an `E3605` field read adds an `E3003`; a layer syntax error
  outside its blocks gives an empty cause.
- **Edit:** a literal re-keyed by assignment (EVAL-LITERALREKEY, 512); re-check against the base (RECHECKBASE,
  506); Refs omits a read under a replaced layer entry (506); the JSON repair limits: single-file `load()`,
  `at:`, non-plain fields, duplicate stems (508).
- ADR-0026 §19's items found while planning (in [plan.md](../plan.md)'s v0.4 and later sections); v0.4 itself is
  formulas ([ADR-0025](../decisions/0025-v04-formulas-outline.md)).

## Not verified

- **Windows and macOS:** no CI; `go vet` only.
- **MSVC:** g++, clang++ and clang++ with libc++ pass; MSVC at scale is a documented limit.
- **Source** was not compiled (its generated output compiles in `make realdata-compile`); **wiki** is not in
  `make realdata-compile`; the services' own CI was not run.
- The same-load A/B ran at load 17-21: its ratios are the evidence, not its wall times.
